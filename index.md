## Portfolio

I'm a Data & Analytics Engineer working across the data lifecycle — ingestion, transformation, warehousing, infrastructure-as-code, and the dashboards on top. Below are a few projects that show how I build and operate data platforms.

**Stack:** Snowflake · Databricks · dbt · Python · SQL · Terraform · Power BI · Azure

### Projects

#### [Retail Analytics on Databricks](https://celinaturner.github.io/DatabricksRetail)

An end-to-end lakehouse on the UCI Online Retail II dataset: medallion architecture (Bronze/Silver/Gold) with dbt transforms and 24 data-quality tests, Unity Catalog governance, Asset Bundle orchestration, and GitHub Actions CI — all on Serverless compute.

![](https://raw.githubusercontent.com/CelinaTurner/databricks-retail-lakehouse/main/images/databricks-lakehouse-architecture.svg)

#### [Snowflake RBAC as Code](https://celinaturner.github.io/SnowflakeRBAC)

A full Snowflake account — warehouses, databases, and a role-based access control model — defined in Terraform and deployed through GitHub Actions, with plan-on-PR / apply-on-merge review gating. Fully reproducible from version control.

![](https://celinaturner.github.io/images/snowflake-rbac-architecture.svg?raw=true)

#### [Medley of Music Analysis](https://celinaturner.github.io/DataMedley)

Exploratory analysis and unsupervised clustering of a Spotify dataset spanning 1900–2021: popularity trends, prolific artists, audio-feature correlations, and K-Means song clusters in Python.
